## Quick Recap: Key Distinctions We Practiced Tonight

| Expression | Meaning & When to Use It | Example |
| :--- | :--- | :--- |
| **`usually`** vs. **`used to`** | **Usually** = normal habit *now*. **Used to** = past habit you *don't do anymore*. *(In questions: `Did you use to...` without `-d`.)* | *"I **usually** pick my daughter up from school."* / *"I **used to** eat mozzarella when I was younger."* |
| **`late`** vs. **`delayed`** | **Late** = missing a scheduled arrival/start time. **Delayed / delay** = an ongoing hold-up while people wait for the next step. | *"Sorry I'm **late**."* / *"Sorry for the **delay** — the train is **delayed**."* |
| **`a half-hour meeting`** | No plural `-s` when a time measurement acts as an adjective before a noun. | *"I was half an hour late to a **half-hour** meeting."* |
| **`worried`** vs. **`concerned`** | **Worried** = emotional/personal. **Concerned** = calm, detached, professional attention to a risk. | *"I'm **concerned** about the manpower levels."* / *"My **concern** is that the customer won't pay."* |
| **`roll out`** *(v.)* / **`rollout`** *(n.)* | Release or deploy a product/feature **gradually** in stages rather than all at once. | *"After beta testing, we'll **roll out** the new features slowly."* |
| **`iron out`** | Remove remaining bugs, defects, or small problems. | *"We need to **iron out** two software bugs before shipping."* |
| **`raise a flag`** | Raise a warning or concern **early** before something breaks. | *"He **raised a flag** about the production line during testing."* |
| **`sign off on`** | Give final, definitive approval (**the green light**) so a phase is done and you can move to the next stage. | *"Once QA **signs off on** testing, we can move to packaging."* |
| **`drowsy`** | Sleepy, heavy-eyed, and foggy (e.g., from medicine or tiredness). | *"The antibiotics made me feel **drowsy**."* |
